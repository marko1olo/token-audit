# Тесты

```
cd tests
python -m unittest discover -s . -v
```

Стандартная библиотека, `unittest`, никаких зависимостей. Настоящие данные,
сеть и Chrome не нужны: всё на синтетических фикстурах, которые собираются на
месте, а ожидаемое число выведено руками и записано в комментарии рядом.
Вывод идёт только в каталог из `tempfile`, в репозиторий тесты не пишут.

## Что каждый тест закрепляет

Все они существуют не «на всякий случай», а из-за уже случившихся аварий.

| файл | инвариант | почему он тут |
|---|---|---|
| `test_dedupe.py` | один `message.id` — один ответ, представитель с максимальной суммой | Claude Code пишет один ответ несколькими записями: по одной на блок содержимого плюс промежуточные снимки, где вывод растёт от 1 до финального. Наивная сумма завышала итог в 2.16 раза |
| | тот же id в двух файлах считается один раз | копирование при `--resume` и компактификации |
| | разбивка записи кэша по TTL доходит до итогов | часовая запись стоит 2× базовой цены ввода против 1.25× пятиминутной; пока поля не было в одном из артефактов, две части инструмента печатали разные суммы на одной странице |
| `test_rates.py` | цены и множители живут в одном месте | копий таблиц ставок было **восемь**: шесть на уровне модулей, седьмая локальными переменными внутри функции (её не видел даже разбор AST), восьмая — таблица OpenAI внутри блока отчёта. Копии `OPENAI` уже разошлись: в одной семь моделей, в остальных одна, при 13 млрд токенов `gpt-5.4` в данных |
| | модель без цены не стоит ноль | ноль в сумме выглядит как измерение |
| | `day_cost` даёт 36.75 на миллион каждого поля | воспроизводит литерал `5 / 6.25 / 0.5 / 25`, который жил в четырёх местах |
| `test_scan_window.py` | окно считается в **байтах**, дописанное после снятия не читается | два прохода по растущему каталогу расходились на 138 ответов и 18 615 694 токена, целиком в модели работающей сессии; доли по моделям давали 100.19% |
| | неполная хвостовая строка отбрасывается | граница режет по байтам, половина записи не разберётся как JSON |
| | свой каталог исключается из обхода | репозиторий лежит внутри `~/.claude/projects` и считал собственные выходные файлы |
| `test_report_engine.py` | пустой блок и чрезмерная усушка отменяют запись | блок, вернувший пустой список, стирал таблицу из 59 строк, файл усыхал на 93.1%, код возврата оставался нулевым. При этом таблица описаний файлов уже рекламировала «защиту от усушки», которой в коде не было |
| | проза вне маркеров не трогается | шаблон таблицы с `re.S` заставил точку совпадать с переводом строки и сожрал документ: 50 814 → 7 697 байт |
| | у каждого маркера `AUTO` есть генератор, реестр не пуст | `report_gen` может выполняться как `__main__`, и обычный импорт создал бы вторую копию модуля с пустым реестром — все блоки молча разрегистрировались бы |
| | `re.S` встречается только в шаблоне маркера | тот же класс аварии |
| `test_verifier_and_config.py` | `&nbsp;`, `&#160;`, `&#xa0;`, `&#8239;`, U+00A0, U+202F, `&thinsp;` — всё нормализуется | шесть ложных отрицательных за одну работу пришли из этого класса |
| | контрольный случай: отсутствующее число действительно не находится | иначе тест на нормализацию доказывает только собственную мягкость |
| | `CLAUDE_CONFIG_DIR` и `CODEX_HOME` учитываются, `archived_sessions` тоже | переменная переносит всё дерево состояния, а её главное применение — переключение аккаунтов, то есть ровно те, кому нужен аудит расхода. `codex archive` переносит сессии в `archived_sessions`, и пока каталог не сканировали, все, кто архивирует, недосчитывались молча |
| | пустой набор корней — ошибка с подсказкой, а не ноль | отсутствующий корень давал нули и код возврата ноль, то есть опубликованное измерение из ничего |
| | `redact` убирает имя пользователя | артефакты публичные |

## Что тестами не покрывается и почему

Честный список, а не умолчание.

- **Полный проход по настоящим транскриптам.** 1.25 ГБ и 1732 файла на этой
  машине. Проверяется только прогоном `python refresh.py`, где сходимость двух
  агрегаторов до токена контролирует блок целостности.
- **Метод chain-split на настоящих данных Codex.** 10 ГБ. Синтетическая фикстура
  на чередующиеся цепочки — следующий очевидный тест, его здесь пока нет.
- **Рендер дашборда.** Нужен headless Chrome. Проверяется этапом 5 в
  `refresh.py`, включая перехват ошибок JavaScript; в CI не запускается.
- **Обнаружение Chrome в реестре Windows.** Ветка платформенная, на Linux
  недоступна.
- **Цифры со второй машины.** Сырых файлов на этой машине нет, только отчёт.
  Класс доказательности у них так и помечен: «по отчёту», не «измерено».
